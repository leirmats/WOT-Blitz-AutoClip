# WoT Blitz AutoClip

Første ordentlige Windows-build av den enkle arbeidsflyten:

1. Dra inn en video eller velg den via Utforsker.
2. Velg tank.
3. Endre filnavn ved behov.
4. Velg lagringsmappe.
5. Trykk START REDIGERING.
6. Programmet finner WoT-kampsekvensene, beholder ca. 1 sekund før kampstart og ca. 10 sekunder etter siste kamp-HUD, og klipper med FFmpeg stream copy.

Programmet skal ikke analysere eller starte videobehandling før START REDIGERING.

Windows-builden pakker FFmpeg og drag/drop-støtte inn i EXE-en.
